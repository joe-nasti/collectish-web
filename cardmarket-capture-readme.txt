Unzip cardmarket-capture.zip. In Chrome Extensions, enable Developer mode and choose Load unpacked, selecting the extracted folder. Pin Collectish Cardmarket Capture. Open a seller inventory page, capture it, then navigate normally and capture more pages. Download captures and import in Collectish > Cartfiller > Cardmarket. The extension sends no network requests and never adds cards to a cart. Cloudflare checks remain part of normal browsing; a blocked page does not replace saved data.
